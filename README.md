# PAPA QUEST Mini App

Рабочий одностраничный прототип домашнего квеста.

## Как открыть

Просто откройте `index.html` в браузере.

## Что уже работает

- стартовый экран;
- карта квартиры;
- 5 этапов;
- последовательное открытие точек;
- загадки и проверка ответов;
- игнорирование регистра, пробелов и ё/е;
- сохранение прогресса через localStorage;
- сброс прогресса;
- финальный экран;
- базовая интеграция Telegram WebApp (`ready`, `expand`, haptic feedback).

## Тестовые ответы

1. зеркало
2. чайник / кофемашина
3. подушка
4. телевизор / тв
5. чемодан / чемоданы

## Как поменять этапы

В `index.html` найдите массив `const quest = [...]`.

У каждого этапа можно поменять:
- `location`
- `clue`
- `answers`
- координаты `map.x`, `map.y`
- `finalText`

## Следующий шаг для Telegram

Разместить страницу на HTTPS-хостинге (например Vercel), создать бота через BotFather и привязать URL Mini App.
